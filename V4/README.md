# IDEA CarHub 360 — طبقة الترخيص (License Layer)

نظام Next.js مستقل بيضيف حماية وترخيص فوق برنامج IDEA CarHub 360 اللي شغال أصلاً على Google Sheet،
وجاهز يترفع على **Vercel** ويتربط بـ **GitHub** و **Supabase** (لمرحلة المزامنة اللحظية القادمة).

---

## 1) الفكرة العامة — Owner Mode (دخول موحّد)

⚠️ **تحديث مهم**: النظام دلوقتي بقى **دخول موحّد بالكامل** — مفيش `/admin/login` ولا `/admin/generate` ولا كوكي أدمن منفصل. كل حد (سواء صاحب البرنامج أو أي عميل) بيدخل من صفحة واحدة (`/client/login`) بكوده، والنظام بيقرر هو مين من عمود **Role** في شيت Licenses:

- **Role = admin** → الكود بتاع صاحب البرنامج. لما يدخل بيه بيفتح البرنامج **كامل بكل صفحاته** من غير أي قيود (allowedPages/allowedCars متجاهلة تمامًا له)، وبيشوف تابين إضافيين جوه صفحة "الإعدادات" (`nav('settings')`): **إدارة التراخيص** و**لوحة تحكم العملاء**. جهازه كمان مش مربوط بـ Device Binding (يقدر يدخل من أي جهاز).
- **Role = client** (أو فاضي) → عميل عادي. صفحة الإعدادات عنده بقت **"الضبط"**: بيانات شخصية + ربط تيليجرام + إعدادات تنبيهات + إدارة سياراته (تعديل/حذف/إضافة). مفيش أي إعدادات سيرفر أو نسخ احتياطي أو منطقة خطر ظاهرة له خالص.

**الشيتات المستخدمة:**
- **Licenses**: زي الأول + عمود جديد **Role** (`admin` أو `client`). لازم تضيفه يدويًا لو الشيت عندك اتعمل قبل التحديث ده (شوف قسم 8 "الترقية من نسخة قديمة").
- **ClientData**: نسخة JSON كاملة من بيانات كل صاحب كود (عرباته، صياناته...). الأدمن كمان ليه صف زي أي عميل عادي (لو حب يجرب البرنامج بنفسه).
- **SharedModels** (شيت جديد، بيتعمل تلقائي): عمودين `Brand`/`Model` — قاعدة بيانات مشتركة، كل عميل يضيف عربية بموديل جديد بيتسجل هنا، ويظهر كاقتراح لباقي العملاء في خانة البحث بالماركة/الموديل.

## 2) تجهيز Google Sheets (Service Account)

1. روح [Google Cloud Console](https://console.cloud.google.com) → أنشئ مشروع جديد (أو استخدم موجود).
2. فعّل **Google Sheets API** من مكتبة الـ APIs.
3. من **IAM & Admin → Service Accounts** أنشئ Service Account جديد.
4. من تبويب **Keys** بتاعه، اعمل **Add Key → Create new key → JSON** ونزّل الملف.
5. من الملف الـ JSON خد:
   - `client_email` → هيبقى `GOOGLE_SERVICE_ACCOUNT_EMAIL`
   - `private_key` → هيبقى `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` (سيبه بنفس الـ `\n` جوه القيمة)
6. افتح Google Sheet بتاعك → **Share** → شارك نفس الـ `client_email` بصلاحية **Editor**.
7. خد الـ Sheet ID من الرابط:
   `https://docs.google.com/spreadsheets/d/`**`SHEET_ID_HERE`**`/edit`

## 3) متغيرات البيئة

انسخ `.env.example` باسم `.env.local` وابدأ التجربة محليًا، واملأ:

| المتغير | الوصف |
|---|---|
| `ADMIN_PASSWORD` | باسورد الأدمن الثابت |
| `SESSION_SECRET` | نص عشوائي طويل (32+ حرف) لتوقيع الجلسات |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | إيميل الـ Service Account |
| `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` | المفتاح الخاص كامل |
| `GOOGLE_SHEET_ID` | ID الشيت |
| `SHEET_TAB_CARS` | اسم تاب العربيات (افتراضي `Cars`) |
| `SHEET_TAB_LICENSES` | اسم تاب التراخيص (افتراضي `Licenses`) |
| `NEXT_PUBLIC_COMPANY_WHATSAPP_NUMBER` | رقم واتساب الشركة (دولي، بدون +) |

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`

```bash
git init
git add .
git commit -m "IDEA CarHub 360 - License Layer"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/idea-carhub-license.git
git push -u origin main
```

بعدين على [vercel.com](https://vercel.com):

1. **Add New Project** → استورد الريبو من GitHub.
2. Framework هيتعرف تلقائي إنه **Next.js**.
3. في **Environment Variables** ضيف كل المتغيرات اللي في `.env.example` (بقيمها الحقيقية).
   - ⚠️ لما تحط `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` في Vercel، حط القيمة كاملة بالـ `\n` زي ما هي (Vercel بيتعامل معاها كنص عادي والكود بيعمل replace تلقائي).
4. اضغط **Deploy**.
5. أي `git push` جديد بعد كده هيعمل Deploy تلقائي (CI/CD جاهز من غير أي إعداد إضافي).

## 5) استخدام النظام

### الدخول (نفس الصفحة للجميع)
- `/client/login` → يدخل أي حد (أدمن أو عميل) بكوده بس. النظام بيقرر الصلاحيات من عمود Role في الشيت.
- أول دخول بيتسجل **Device ID** تلقائي (fingerprint متخزن في المتصفح) ويترابط بالكود — **إلا كود الأدمن**، اللي معفي من قيد الجهاز.
- لو نفس كود العميل اتفتح من متصفح/جهاز تاني → هيترفض برسالة "الكود مفعّل على جهاز آخر".
- لو الكود منتهي → تحويل تلقائي لصفحة `/expired` فيها رسالة + زرار واتساب لرقم الشركة.
- كل دقيقة بيتعمل تحقق حي (`/api/client/session`) من حالة الترخيص، فلو اتغيّر شيء أثناء الاستخدام هيتفعّل فورًا.

### تجربة العميل العادي (Role = client)
- بيشوف البرنامج بصفحاته المسموح له بيها بس (اللي الأدمن فعّلها له وقت توليد الكود)، ومحدود بعدد العربيات المسموح بيه.
- صفحة "الإعدادات" عنده بقت **"الضبط"**: بيانات شخصية (اسم + موبايل + ربط تيليجرام)، إعدادات تنبيهات (كم/يوم قبل الصيانة والرخصة)، وإدارة سياراته (عرض كروت + تعديل + حذف + إضافة سيارة جديدة، بحد أقصى Allowed Cars).
- **مفيش أي وصول لإعدادات السيرفر أو النسخ الاحتياطي أو "منطقة الخطر" خالص.**

### تجربة الأدمن (Role = admin)
- بيدخل بنفس صفحة `/client/login` بكوده الخاص، وبيفتح البرنامج **كامل من غير أي قيود صفحات أو عدد عربيات**.
- من صفحة "الإعدادات" بتاعته، فيه 4 تابات:
  1. **عام**: إعدادات التنبيهات (نفس اللي عند العميل).
  2. **إدارة التراخيص**: توليد كود جديد (اسم، موبايل، أيام، عدد عربيات، سوتشات الصفحات) + جدول بكل الأكواد وأزرار تمديد/إيقاف/تفعيل/حذف.
  3. **لوحة تحكم العملاء**: جدول بكل العملاء (الاسم، الكود، عدد العربيات، آخر مزامنة) + زرار "عرض كعميل" يوريه عربيات أي عميل.
  4. **إعدادات متقدمة**: رابط سيرفر بوت تيليجرام، تصدير/استيراد نسخة احتياطية، ومسح كل البيانات — دول مخفيين تمامًا عن أي عميل عادي.

## 6) ملاحظات مهمة

- **"استهلاك الكود لمرة واحدة"**: الكود بيترابط بأول جهاز يفتحه (Device Binding)، وبعدها أي محاولة دخول من جهاز مختلف بترفض تلقائيًا — وده هو المطلوب فعليًا (منع مشاركة نفس الكود بين أكتر من جهاز).
- **Device ID الحالي** عبارة عن fingerprint بيتخزن في `localStorage` بالمتصفح. ده كافي لمعظم الحالات، لكنه مش "hardware lock" فعلي (لو العميل مسح بيانات المتصفح هيتولد ID جديد). لو حابب قفل أقوى على مستوى الجهاز الفعلي (مش المتصفح) محتاجين تطبيق مصاحب (Electron/PWA) وده خطوة تالية ممكن نضيفها.
- **Supabase**: الهيكلة الحالية معمولة بحيث كل منطق البيانات معزول في `lib/googleSheets.js`. لما تكون جاهز، ممكن نضيف `lib/supabase.js` بنفس الشكل ونفعّل مزامنة لحظية (Realtime) بدل الاعتماد على استعلام كل دقيقة، من غير ما نلمس صفحات الواجهة أو منطق الترخيص.
- **البرنامج الأصلي متضمّن بالكامل** في `public/app/index.html` (نفس الملف اللي جهزناه بدمج بيانات العربيات + البحث بالحروف)، مع سكريبت إضافي في آخره (`ideaBootstrap` وما حوله) بيوصله بـ Google Sheet عن طريق نظام الترخيص. أي تحديث تعمله على البرنامج نفسه مستقبلًا، حاول تحافظ على الأجزاء دي (تلاقيها في تعليقات `IDEA license/sync bridge`).
- شيت **Cars** والـ endpoint `/api/client/cars` (فلترة بعمود `Owner ID`) لسه موجودين في المشروع كخيار بديل/احتياطي لو حبيت مستقبلًا تفصل البيانات لأعمدة بدل الـ JSON blob، لكنهم مش مستخدمين في التدفق الحالي.
- **قاعدة بيانات الموديلات المشتركة**: كل ما عميل يحفظ عربية بماركة/موديل، بيتبعت (fire-and-forget) لشيت `SharedModels`، وبيظهر كاقتراح لكل العملاء التانيين في خانة البحث بالحروف — من غير ما تحتاج تحدّث `BRANDS_DB` يدويًا في الكود.

## 7) أول تشغيل: إزاي تعمل كود الأدمن (صاحب البرنامج)؟

النظام معندوش باسورد ثابت للأدمن دلوقتي — أي كود بعمود Role بتاعه = `admin` بيدخل كأدمن. أسهل طريقة تعمل أول كود:

1. افتح Google Sheet بتاعك → تاب **Licenses** (لو مش موجود، افتح `/client/login` مرة عشان يتعمل تلقائي أول ما حد يحاول يدخل).
2. ضيف صف يدوي بنفسك:
   - `Code`: أي كود تختاره (مثلاً `IDEA-OWNER`)
   - `Client Name`: اسمك
   - `Status`: `Active`
   - `Expiry Date`: تاريخ بعيد (مثلاً بعد 10 سنين)
   - `Role`: **admin**
   - باقي الأعمدة سيبها فاضية.
3. ادخل بيه من `/client/login`.

بعد كده تقدر تولّد بيه أي كود عميل عادي من تاب "إدارة التراخيص" جوه البرنامج.

### الترقية من نسخة قديمة من الشيت
لو شيت Licenses بتاعك اتعمل قبل التحديث ده، مش هيبقى فيه عمود **Role**. ضيفه يدويًا كعمود أخير، واسيب خانته فاضية لأي عميل عادي (النظام بيتعامل مع الفاضي كـ `client` تلقائيًا).

## 8) هيكل المشروع

```
app/
  page.js                        بيحوّل مباشرة لـ /client/login (نقطة دخول موحّدة)
  client/login/page.js           دخول موحّد بالكود (أدمن أو عميل)
  client/dashboard/page.js       يتحقق من الترخيص ويحمّل البرنامج في iframe
  expired/page.js                صفحة انتهاء الفترة التجريبية
  api/client/login, logout, session, appdata, cars   APIs الدخول والمزامنة
  api/admin/licenses, licenses/[code], clientdata/[code], customers   APIs خاصة بالأدمن (بتتنادى من داخل تابات "الإعدادات" في البرنامج نفسه)
  api/shared/models              اقتراحات الموديلات المشتركة بين كل العملاء
lib/
  googleSheets.js                طبقة القراءة/الكتابة على الشيت (Licenses / ClientData / SharedModels)
  auth.js                        جلسة موحّدة (JWT cookie) فيها الـ Role
  license.js                     منطق الكود/الانتهاء/الصفحات المسموحة
  deviceId.js                    فحص الجهاز في المتصفح
middleware.js                    حماية أولية لصفحة /client/dashboard
public/app/index.html            البرنامج الأصلي كامل + سكريبت "IDEA license/sync bridge" في آخره
```
